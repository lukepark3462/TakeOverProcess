# 송림3지구 신임 집행부 재구성 | TakeOverProcess

2026년 10월 19일 기준 **최종 주차별 실행 로드맵(김명숙 사퇴 6~8주 / 잔류 4~6주)**을 웹으로 재구성한 정적 홈페이지입니다.

## 홈페이지 구성
- **종합 현황**: 프로젝트 개요, 주요 수치, 최근 경과, 시나리오 개요
- **주차별 로드맵**: 두 시나리오의 전체 업무·예상 주차·추진 내용·근거 조항
- **정관·규정 근거**: 정관(안), 선거관리규정 변경(안) 조항별 요지 및 적용 업무
- **추진 경과**: 2026.10.16 임원 해임총회 등 기본 기록과 GitHub Issues의 최신 `[진행]` 기록
- **경과 등록·관리**: 내용 입력 → GitHub Issue 작성 화면 열기

## 진행 경과 추가하기 (가장 쉬운 방법)
1. 홈페이지에서 **경과 등록·관리** → 날짜·제목·상태·내용 입력
2. **GitHub 경과 등록 화면 열기**를 눌러 Issue 작성 페이지로 이동
3. GitHub 로그인 후 **Submit new issue** 클릭
4. 홈페이지 새로고침 → **추진 경과**에 자동 표시

직접 GitHub Issues에서 만들 경우 제목은 **`[진행] 주요 업무 제목`** 형식, 본문은 다음 구조를 준수해야 합니다.

```text
일자: 2026-10-20
대상: 공통
상태: 진행 중
담당: 선거관리위원회
내용:
진행 경과 및 확인 근거를 기재
```

대상에는 `공통`, `시나리오 1`, `시나리오 2` 중 하나를 사용합니다.

## 로드맵 및 정관 근거 수정
`data.js` 파일은 실제 홈페이지에 쓰이는 업무 데이터입니다.
- `tracks`: 시나리오별 일정과 세부 단계
- `milestones`: 초기 확정 기록
- `sources`: 조항별 정관·선관위 규정 설명
- `notices`: 자료 성격 및 일정 유의사항

추가 진행 기록을 갱신할 때마다 **`index.html`을 수정할 필요는 없습니다.**

## 홈페이지 공개
저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch / main / (root)**를 선택하여 저장하면 됩니다. GitHub Pages 공개 주소는 일반적으로 다음과 같습니다.

https://lukepark3462.github.io/TakeOverProcess/

GitHub Pages 설정이 활성화되기 전에는 주소가 404를 표시할 수 있습니다.

## 주의
- Public 저장소와 GitHub Issues에 작성한 모든 내용은 인터넷에 공개됩니다. 개인정보, 민감한 내부 논의, 비공개 조합 문서 등은 게시하지 마세요.
- 문서 근거는 제공된 **정관(안) 및 선거관리규정 변경(안)** 기준입니다. 시행 중인 규정의 최종 내용은 별도 확인이 필요합니다.
- 기간은 **목표일정**입니다. 조합장 선출 후 변경인가·등기는 추가 기간이 소요될 수 있습니다.
- 자료는 의결 또는 승인 사실에 대한 공식 공고가 아닙니다.

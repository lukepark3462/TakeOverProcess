# 송림3지구 조합원 비상대책위원회 — TakeOverProcess

## 일반 방문자
공개 홈페이지는 **조회 전용**입니다. 홈페이지 내부의 편집 링크와 경과 등록 버튼은 제거했으며, 공개 GitHub Issues의 내용을 홈페이지에 자동 표시하지 않습니다.

- 비대위 및 운영 방향 소개
- 조합원 연명 기반 대의원회 소집·임원 보궐선임 주차별 실행계획
- 확인된 진행 경과와 실제 기록일
- 수입·지출 내역 및 집계 잔액
- 공개 동의가 있는 후원자 정보
- 비대위 구성 및 관련 정관·선거관리규정 요지

[홈페이지 열기](https://lukepark3462.github.io/TakeOverProcess/)

## 데이터 관리 (GitHub 저장소 쓰기 권한이 있는 운영자만)
현재 단일 정상화 실행계획 및 진행 경과는 `data.js`, 재정·후원자 정보는 `finance.js`에서 관리합니다. 사이트에 편집 기능이 없으므로 일반 방문자는 이를 변경할 수 없습니다.

**참고:** 저장소가 Public인 이상 파일 원문 자체는 공개 조회가 가능합니다. 편집 버튼을 숨기는 것은 보안 권한 설정과 다릅니다. GitHub 저장소 쓰기 권한을 가진 사용자만 GitHub에서 파일을 변경할 수 있습니다.

## 추후 Excel 기반 관리 예정
회계와 진행 경과를 Excel로 관리할 경우 다음 두 작업을 분리하여 운영할 예정입니다.

1. 비공개 원본 Excel: 날짜, 수입·지출, 영수증, 후원 내역 등 상세 자료 관리. **개인정보와 내부 자료가 있는 Excel 원본을 공개 GitHub 저장소에 올리지 않습니다.**
2. 홈페이지 공개용 데이터: Excel에서 공개 가능한 열만 변환하여 웹 데이터 갱신. 공개 동의 없는 이름은 익명 처리. 변경 사항과 최종 업데이트일만 사이트에 표시.

**업데이트 방식 선택지**
- 대화에서 Excel 파일을 전달하면 내용을 검증·정리하여 사이트 데이터에 반영 (수동·검토형).
- Excel을 정해진 폴더에 올릴 때 GitHub Actions가 공개용 JSON으로 변환하게 만드는 자동화형. 이 경우 공개 저장소에 개인정보가 담긴 원본 파일을 업로드하지 않도록 별도의 비공개 저장소 또는 비공개 처리 경로가 필요.

엑셀 실제 양식이 준비되면 그 열 구조에 맞춰 가져오기 및 검증 규칙을 설정합니다.

## 디자인 색상 기준 (고정)

공식 매체 공통 규격은 [송림3지구 디자인 시스템 공식 기준서](DESIGN_SYSTEM.md)를 따릅니다. PPT·홈페이지·인포그래픽 등 모든 신규·수정 제작물은 이 규격만 사용하며, 사용자의 명시적 변경 지시 전까지 임의 테마를 도입하지 않습니다. 프로세스의 실제 표시색은 `--sg-process` = 밝은 틸 `#9DD5CD`입니다.

이 저장소의 색상 기준은 **사용자가 제공한 ‘Color Palette Analysis Guide’(2026.10)** 이며, 앞으로의 모든 수정·추가 화면에 **`palette.css`의 컬러 토큰**을 적용합니다. 기존의 임의 딥그린·아이보리 색상 체계로 되돌리지 않습니다.

- 브랜드/핵심: Green `#86BC25` · Deep Green `#076638`
- 수치/재무 데이터: Blue `#0272A6`
- 프로세스/진행: Teal `#05767D`
- 부가설명/보조: Gray `#75797A`
- 비용 금액/예외 강조: Red `#E12211` (검정 배경에서는 이 색의 밝은 톤 사용 가능)
- 배경과 본문 대비: Black `#000000`, White `#FFFFFF`

### TRANSACTION RECORDS 표시 규칙

방문자 화면에는 개별 이체 상세 행을 나열하지 않고, **월 / 계정 / 내용에 대한 설명 / 금액 / 잔액** 5열의 월별·계정별 집계만 표시합니다. 2026년 10월 19일 기준 기존 입금액은 모두 **2026년 9월**로 집계합니다. 금액의 + 기호는 초록색, − 기호는 회색, 지출액 숫자는 빨간 계열, 잔액은 데이터 블루 계열로 처리합니다. 방문자 화면에는 상계성 환불 1,200,000원을 수입·지출 양쪽에서 제외하고 ‘상계·정산’ 항목을 노출하지 않습니다. 20,000원은 기존 요청에 따라 **기타 비용**으로 반영합니다. 거래표는 9월 수입 한 줄과 9월·10월 지출 합계 두 줄이 기본이며, 각 지출 행의 ‘펼쳐보기’로 계정별 집계를 볼 수 있게 합니다. 도넛차트 역시 상계 환불을 제외한 지출 **27,670,510원** 기준으로 집계합니다.
